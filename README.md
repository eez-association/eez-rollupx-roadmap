# EEZ RollupX Roadmap

Strawmap-style roadmap built from the cards on the [EEZ RollupX project board](https://github.com/orgs/eez-association/projects/1/views/1).

- `roadmap.html` is the source (also published as a claude.ai Artifact).
- `./build.sh` wraps it into `index.html`, served by GitHub Pages from `main` at https://eez-association.github.io/eez-rollupx-roadmap/. Run it after every edit, then push.

Snapshot of the board on 17 November 2026. Columns are horizons, not dates; north stars are drafts.
